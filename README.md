# Сайт усадьбы Михайловское

Статический сайт (HTML + CSS + JS), без сборки. Открывается двойным кликом по `index.html`.

## Структура

Все файлы лежат в одной папке, без подпапок:
```
index.html   — главная (лендинг)
guide.html   — страница объекта парка для QR-кодов: guide.html?place=alleya
style.css    — стили и фирменные цвета
data.js      — ВСЕ тексты событий, объектов парка и тура — правьте здесь
main.js      — логика
*.jpg        — картинки
Ametist.woff2 — (по желанию) фирменный шрифт заголовков
audio-alleya.mp3, audio-dom.mp3 … — (по желанию) аудиогиды
```

## Что поправить перед запуском

1. **События** — `data.js`, массив `EVENTS` (даты, цены, тексты сейчас примерные).
2. **Контакты** — телефон, почта, адрес и часы работы в `index.html`, раздел «КОНТАКТЫ».
3. **Заявки** — зарегистрируйтесь на formspree.io, создайте форму и вставьте её адрес
   в `main.js` → `const FORM_ENDPOINT = "https://formspree.io/f/xxxx";`
4. **Оплата билетов** — подключите сервис продажи билетов (Радарио, Intickets, TicketsCloud и т.п.)
   и замените кнопку «Записаться» на их виджет или ссылку.
5. **Яндекс Метрика** — вставьте код счётчика в `<head>` обеих страниц.
6. **Шрифт Ametist** — положите файл `Ametist.woff2`; без него используется Kurale.
7. **Панорамы 360°** — для настоящего тура подключите библиотеку Pannellum.

## QR-коды

Ссылка для таблички: `https://<ник>.github.io/<репозиторий>/guide.html?place=<id>`
Список id — ключи объекта `PLACES` в `data.js` (dom, oranzhereya, alleya, angl, botsad, aromat, tropa, vodoem, scena, kofe).
