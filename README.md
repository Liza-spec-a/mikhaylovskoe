## О сайте

По нашей концепции усадьба становится общественным пространством: выставки, лекторий, мастер-классы, иммерсивные вечера и открытый парк. Сайт нужен, чтобы люди узнавали обо всём этом и приходили. Что он делает:

- **собирает всю программу в одном месте** — посетители смотрят афишу и записываются онлайн;
- **приносит доход** — билеты, платные мастер-классы и заявки на аренду площадок;
- **рассказывает историю без табличек в интерьерах** — главный дом, флигели и часовни являются объектами культурного наследия, поэтому рассказ об усадьбе вынесен в цифровой формат и QR-коды.

### Разделы

| Раздел | Что там |
|---|---|
| Главная | коротко об усадьбе, 4 направления концепции, ближайшие события |
| Афиша | выставки, лекции, мастер-классы, экскурсии, иммерсивный бал, кино; фильтр по типу и запись на событие |
| История | таймлайн 1776–1960, Шереметевы, ботанический сад, выставка минералов, архивные фото |
| Карта парка | интерактивная схема: нажимаешь на зону — появляется описание |
| Виртуальный тур | фото залов и галерей, картинку можно тянуть мышкой или пальцем |
| Аренда | площадки и форма заявки |
| Контакты | адрес, часы работы, автобусы, расстояния, Яндекс Карта |

Отдельно есть страница **`guide.html`** — на неё ведут QR-коды в парке. Там описание объекта и аудиогид.

### Стиль

Стиль взят из нашей презентации.

- Цвета: тёмно-зелёный `#203327`, фирменный зелёный `#569365`, белый `#FFFFFF`, золотисто-бежевый `#E1C796`, кремовый `#FBEACA`
- Шрифты: заголовки — Ametist (если файла нет, подставляется Kurale), основной текст — Manrope
- Орнамент — четырёхконечная звезда, логотип — монограмма усадьбы

Все цвета заданы в начале `style.css` (блок `:root`), и если поменять их там, они поменяются на всём сайте.

Сайт адаптивный, потому что большая часть посетителей будет открывать его с телефона, в том числе по QR-кодам прямо в парке.

## Шпаргалка для того, кто будет вести сайт

Сайт простой — HTML, CSS и JavaScript, без программ и сборки. Чтобы посмотреть сайт у себя, достаточно двойного щелчка по `index.html`. Редактировать можно в любом текстовом редакторе (подойдёт VS Code, он бесплатный), а **Word для этого не подходит**.

### Где что лежит

```
index.html     — главная страница со всеми разделами
guide.html     — страница для QR-кодов (описание + аудиогид)
data.js        — афиша, объекты парка, виртуальный тур  ← правится чаще всего
style.css      — оформление и цвета
main.js        — логика: фильтры, запись, карта, формы
*.jpg          — картинки
```

### Как добавить или изменить событие в афише

Открыть `data.js` и найти список `EVENTS`. Каждое событие — это вот такой блок:

```js
{ id: "keramika", cat: "Мастер-класс", title: "Керамическая мастерская",
  date: "2026-11-15", time: "12:00", price: 1800, img: "flower.jpg",
  text: "Лепим вазу или тарелку с растительным орнаментом..." },
```

- `id` — короткое имя латиницей, у каждого события своё
- `cat` — тип события. Из этих типов сами собираются кнопки-фильтры
- `date` — пишется строго как **ГГГГ-ММ-ДД**, сайт сам сортирует события по дате
- `price` — цена в рублях, **0 = бесплатно**
- `img` — имя картинки, которая лежит рядом с остальными файлами

Чтобы добавить новое событие, скопируй блок целиком вместе с `{ }` и запятой в конце и поменяй значения. Прошедшие события можно просто удалить. В разделе «Ближайшие события» на главной сами показываются три ближайших.

> ⚠️ Самая частая ошибка — пропущенная запятая или кавычка. Если афиша вдруг пропала, проверь последние правки.

### Как поменять текст на странице

Тексты разделов лежат в `index.html`. Найди нужную фразу поиском (Cmd+F / Ctrl+F), поменяй и сохрани. Теги в угловых скобках `< >` трогать не нужно.

### Объекты парка и QR-коды

Объекты карты описаны в `data.js` в блоке `PLACES`. У каждого объекта есть id:

`dom` — главный дом, `oranzhereya` — оранжерея, `alleya` — липовая аллея, `angl` — английский сад, `botsad` — ботанический сад, `aromat` — сад ароматов, `tropa` — сенсорная тропа, `vodoem` — пруд, `scena` — сцена, `kofe` — кофейня

Ссылка для QR-кода:

```
https://<адрес сайта>/guide.html?place=alleya
```

Готовую ссылку вставляешь в любой бесплатный генератор QR-кодов. Перед тем как печатать табличку, отсканируй код своим телефоном и проверь, что он открывается.

### Аудиогид

Записываешь mp3 и называешь файл `audio-<id>.mp3`, например `audio-alleya.mp3`, потом загружаешь его рядом с остальными файлами. Пока файла нет, текст читает голос браузера. Так работает, но звучит хуже, поэтому лучше записать настоящий аудиогид.

### Картинки

Фото загружаются рядом с остальными файлами. Имя пиши латиницей без пробелов (`zal-2.jpg`). Желательно ужимать фото до ~1600 px по ширине, иначе сайт будет долго грузиться с телефона. Пережать фото можно, например, на squoosh.app.

## Что ещё нужно подключить

- [ ] **Заявки с форм.** Сейчас форма только показывает «Спасибо», и заявки никуда не уходят. Чтобы они приходили на почту: зарегистрироваться на formspree.io → создать форму → скопировать адрес вида `https://formspree.io/f/xxxx` → вставить в `main.js` в строку `const FORM_ENDPOINT = "";`
- [ ] **Оплата билетов.** Подключить сервис продажи билетов (Радарио, Intickets, TicketsCloud или другой) и поставить его виджет или ссылку на кнопку «Записаться».
- [ ] **Яндекс Метрика.** Создать счётчик на metrika.yandex.ru и вставить его код в `<head>` обеих страниц, там есть комментарий-подсказка. Тогда будет видно, какие разделы и события интересуют людей больше всего.
- [ ] **Контакты.** Вписать настоящие телефон и почту, проверить адрес и часы работы (раздел «КОНТАКТЫ» в `index.html`).
- [ ] **Афиша.** Даты, цены и описания событий сейчас примерные, их надо заменить на настоящие.
- [ ] **Шрифт Ametist.** Положить файл `Ametist.woff2` рядом с остальными файлами, он подхватится автоматически.
- [ ] **Виртуальный тур.** Сейчас в туре обычные фото. Для настоящих панорам 360° можно подключить бесплатную библиотеку Pannellum.

## Как сайт опубликован (GitHub Pages)

Сайт лежит в репозитории на GitHub и публикуется через GitHub Pages бесплатно.

**Как обновить сайт:**
1. Открыть репозиторий на github.com
2. **Add file → Upload files**, перетащить изменённые файлы (одноимённые файлы заменятся)
3. Нажать **Commit changes**
4. Подождать 1–2 минуты и обновить страницу сайта

Мелкую правку можно сделать прямо на GitHub: открыть файл → значок карандаша → исправить → **Commit changes**.

**Если обновление не видно:** обнови страницу с очисткой кэша (Cmd+Shift+R / Ctrl+F5). Статус публикации виден во вкладке **Actions**: зелёная галочка значит, что всё опубликовалось.

**Свой домен:** Settings → Pages → Custom domain.

> Safari не умеет загружать папки на GitHub, поэтому все файлы сайта лежат в одной папке. Если будешь добавлять новые файлы, клади их туда же.
